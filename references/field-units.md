# 項目の意味と単位

## 求める材料

| 材料 | 種類 | 必須 | 形 | 無いとき |
|---|---|---|---|---|
| 知りたい項目、または足したい列 | 対象の属性 | ○ | RENPHOのキー、または意味の名前 | 判断できない |
| 体組成計の機種 | 導入先の環境 | — | 機種名 | Elis Aspireで確かめた結果として答え、他の機種では確かめていないと添える |

## 答え

1. **APIは単位を返さない。名前からも判別できない。推測で項目を対応付けない。** 下の表の意味と単位を使う。

| RENPHOのキー | 意味 | 単位 |
|---|---|---|
| `weight` | 体重 | kg |
| `bmi` | BMI | — |
| `bodyfat` | 体脂肪率 | % |
| `water` | 体水分率 | % |
| `muscle` | **骨格筋量** | kg |
| `sinew` | **筋肉量** | kg |
| `bone` | 骨量 | kg |
| `bmr` | 基礎代謝 | kcal/日 |
| `visfat` | 内臓脂肪レベル | レベル |
| `subfat` | 皮下脂肪率 | % |
| `protein` | タンパク質率 | % |
| `bodyage` | 体年齢 | 歳 |
| `fatFreeWeight` | 除脂肪体重 | kg |
| `TW` | 標準体重 | kg |
| `WC` | 標準体重までの増減（体重コントロール） | kg |
| `resistance` | 生体インピーダンス | Ω |
| `bodytype` | 体型分類 | コード |

2. **`FC` は `WC` の重複。列を作らない。**
3. **`muscle` と `sinew` を取り違えない。** `muscle` が骨格筋量で、`sinew` が筋肉量。名前の印象と逆になる。
4. **機種によって返らない項目がある。** Elis Aspireでは `heartRate`・`cardiacIndex`・`bodyShape` が常に空（心拍センサ非搭載）。
5. **記録先に列を足す前に、必ず実データで値が入っているかを確かめる。**

## 道具

- 意味・単位・丸めの桁は `renpho_records.FIELDS` が持つ。`normalize(record)` は、このキーのうち有効な値だけを返す。
- 答え5は `uv run scripts/probe_fields.py --limit 3`。全件を走査し、値が入っている項目と、常に空の項目を出す。どこにも書き込まない。

## 値

丸めの桁は作成者が決めた値。`renpho_records.FIELDS` の定数が正（多くのスキルがimportする道具なので、表を読まない）。

| 名前 | 値 | 単位 |
|---|---|---|
| 体重・率・kg単位の項目の丸め | 小数1桁 | — |
| 骨量の丸め | 小数2桁 | — |
| 基礎代謝・内臓脂肪レベル・体年齢・生体インピーダンス・体型分類 | 整数 | — |

## 理由

2026-08-08に、取得できた全件で次の恒等式を検証して確定した。

| 恒等式 | 成立 | 結論 |
|---|---|---|
| `weight * (1 - bodyfat/100) == fatFreeWeight` | 全件 | `bodyfat` は% |
| `sinew + bone == fatFreeWeight` | ほぼ全件（丸めのずれのみ） | `sinew` は筋肉量（kg） |
| `muscle < sinew` | 全件 | `muscle` は骨格筋量（kg） |
| `subfat < bodyfat` | 全件 | `subfat` は% |
| `weight + WC == TW` | 全件 | `TW` は標準体重（kg）、`WC` は標準体重までの増減（kg） |
| `FC == WC` | 全件 | `FC` は `WC` の重複 |

- 丸めの桁を決めた理由は、記録が無い（→ SKILL.md の未決）。

## 却下した案

| 案 | 理由 |
|---|---|
| キーの名前から意味を推測する（`muscle` を筋肉量とする） | 恒等式で逆だと分かった（答え3） |
| 返ってくるキーをすべて列にする | 常に空の項目と重複（`FC`）が混ざる |

## 当てはまる範囲と限界

- Elis Aspireで確かめた。他の機種では、`probe_fields.py` と恒等式で確かめ直す。
- `bodytype` のコードが何を指すかは確かめていない（数値のまま持つ）。
