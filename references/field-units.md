# 項目の意味と単位

## 扱うこと

項目を記録先の列に対応付ける・列を足すとき、どのキーが何で、単位は何か。どの項目に列を作るか

## 答え方と理由

### 0. 判断全体

体組成計が Elis Aspire のときに、次のとおりにする。ほかの機種では、答え方5のとおりに確かめ直す（未決 U1）。`bodytype` のコードが何を指すかは、この判断では答えない（数値のまま持つ）。

### 1. 単位を推測せず、この表の意味と単位を使う

APIは単位を返さず、名前からも判別できない。キーの名前から意味を推測して対応付けない。下の表の意味と単位を使う。

| RENPHOのキー | 意味 | 単位 |
|---|---|---|
| `weight` | 体重 | kg |
| `bmi` | BMI | — |
| `bodyfat` | 体脂肪率 | % |
| `water` | 体水分率 | % |
| `muscle` | 骨格筋量 | kg |
| `sinew` | 筋肉量 | kg |
| `bone` | 骨量 | kg |
| `bmr` | 基礎代謝 | kcal/日 |
| `visfat` | 内臓脂肪レベル | レベル |
| `subfat` | 皮下脂肪率 | % |
| `protein` | タンパク質率 | % |
| `bodyage` | 体年齢 | 歳 |
| `fatFreeWeight` | 除脂肪体重 | kg |
| `TW` | 標準体重 | kg |
| `WC` | 標準体重までの増減（体重コントロール） | kg |
| `resistance` | 生体インピーダンス | Ω |
| `bodytype` | 体型分類 | コード |

1. （知見）取得できた全件で、次の恒等式を検証して確定した。`weight * (1 - bodyfat/100) == fatFreeWeight`（全件。`bodyfat` は%）・`sinew + bone == fatFreeWeight`（丸めのずれを除き全件。`sinew` は筋肉量）・`muscle < sinew`（全件。`muscle` は骨格筋量）・`subfat < bodyfat`（全件。`subfat` は%）・`weight + WC == TW`（全件。`TW` は標準体重、`WC` は標準体重までの増減）。（実測：記録なし〜2026-08-08・取得できた全件）

### 2. `FC` に列を作らない

`FC` は `WC` の重複。列を作らない。返ってくるキーをすべて列にしない。

1. （知見）`FC == WC` が全件で成り立った。（実測：記録なし〜2026-08-08・取得できた全件）
2. （根拠）返ってくるキーをすべて列にすると、常に空の項目と重複（`FC`）が混ざる。（決定日：記録なし）

### 3. `muscle` と `sinew` を取り違えない

`muscle` が骨格筋量で、`sinew` が筋肉量。名前の印象と逆になる。`muscle` を筋肉量としない。

1. 答え方1の理由1と同じ。

### 4. 機種によって返らない項目がある

機種によって返らない項目がある。Elis Aspireでは `heartRate`・`cardiacIndex`・`bodyShape` が常に空（心拍センサ非搭載）。

1. 記録なし

### 5. 列を足す前に、実データで値が入っているかを確かめる

記録先に列を足す前に、必ず実データで値が入っているかを確かめる。

1. 記録なし

## 判断定数

多くのスキルがimportする道具なので、道具はこの表を読まない。正は `renpho_records.FIELDS` の定数で、この表は写し。

| 名前 | 値 | 単位 | 理由 |
|---|---|---|---|
| 体重・率・kg単位の項目の丸め | 1 | 小数の桁 | 記録なし |
| 骨量の丸め | 2 | 小数の桁 | 記録なし |
| 基礎代謝・内臓脂肪レベル・体年齢・生体インピーダンス・体型分類の丸め | 0 | 小数の桁 | 記録なし |

## 未決

- U1：Elis Aspire 以外の機種で、答え方1の恒等式が成り立つかは確かめていない。暫定の扱い：ほかの機種では `probe_fields.py` と恒等式で確かめてから対応付ける。

## 求める材料

| 材料 | 種類 | 必須 | 形 | 無いとき |
|---|---|---|---|---|
| 知りたい項目、または足したい列 | 対象の属性 | ○ | RENPHOのキー（例：`"muscle"`）、または意味の名前（例：`"骨格筋量"`） | 判断できない |
| 体組成計の機種 | 導入先の環境 | — | 機種名（例：`"Elis Aspire"`） | Elis Aspireで確かめた結果として答え、他の機種では確かめていないと添える |

## 計算

なし

## 道具

答え方1・3：意味・単位・丸めの桁は `renpho_records.FIELDS` が持つ。`normalize(record)` は、このキーのうち有効な値だけを返す。

答え方5：`uv run <skill-dir>/scripts/probe_fields.py --limit 3` が、全件を走査し、値が入っている項目と、常に空の項目を出す。どこにも書き込まない。
